Сведения о публикации

Название: «Указания по применению схемы DCC для создания цифрового сертификата калибровки неавтоматических весоизмерительных приборов. Экспертный отчёт DKD-E 7-3».

PTB, 2025; редакция 03/2025; 60 страниц, английский язык. DOI: 10.7795/550.20250325. Редактор: Немецкая калибровочная служба (DKD).

Краткое содержание по-русски

Руководство описывает применение XML-схемы цифрового сертификата калибровки DCC к неавтоматическим весам. Универсальная схема требует предметных уточнений, подготовленных экспертами технического комитета DKD по массе и весоизмерительным приборам. Рассматриваются калибровки по EURAMET Calibration Guide № 18, версия 4.0; часть рекомендаций применима и к другим процедурам. Основное внимание уделено гибкой информации сертификата. Рекомендации во многих случаях можно использовать для гирь и эталонов плотности.

Отчёт ссылается на схему DCC 3.3.0; при реализации рекомендуется сверяться с актуальной схемой. Развитие цифровых сертификатов требует учитывать возможные изменения схемы и согласованных атрибутов refType. Это описание документа, а не инструкция по реализации.
