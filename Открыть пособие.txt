МЕТРОЛОГИЯ — ЭЛЕКТРОННОЕ ПОСОБИЕ

Для чтения откройте index.html современным браузером.
Сохраняйте рядом с ним sources.html и папки assets и chapters:
их имена и взаимное расположение нужны для ссылок, оформления и рисунков.

Для чтения учебного материала подключение к Интернету не требуется.
Интернет нужен только для перехода к внешним источникам.

Проверка интерфейса выполнена через локальный сервер. Открытие через
file:// не подтверждено браузерной проверкой: встроенный браузер запретил
этот способ доступа. В коде нет загрузки учебного содержания через fetch,
внешних шрифтов, CDN и других обязательных сетевых зависимостей.

Для будущей публикации загрузите index.html, sources.html, все остальные
HTML-страницы и папки assets и chapters, сохранив их структуру.
Папка tools и этот текстовый файл для публикации не нужны.
